# Chapter 22 figure storyboard

Six editable TikZ figures have matching semantic UTF-8 descriptions. Biological
names refer to proposed software contracts, not to biological fidelity.

1. **Selective fast-state update.** Learned gates combine old state and proposal;
   the arrows implement the equations, not an unqualified genomic analogy.
2. **Complete causal carry.** Both fast state and locus memory cross chunk
   boundaries. Only prefix tokens enter a causal output.
3. **Offline dual representation.** Shared-weight forward and reverse-complement
   passes are realigned before a symmetric readout. This is not a causal LM input.
4. **Read before write.** Output reads old locus memory; the updated locus bank is
   carried to the next step. The order is part of this chapter's cell definition.
5. **Executed falsification controls.** Causal perturbation, complete carry,
   gradient parity, request isolation, exact motif oracle and independent labels
   are distinct checks. A small pilot is not a matched-budget benchmark.
6. **Scalar memory trace.** A convex write moves 0.2 toward proposal 0.8 by gate
   0.25, giving 0.35. Generated trace tables check the illustrated arithmetic.
