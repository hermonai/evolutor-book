# Chapter 31 storyboard — authored before the rewrite

Question: how can a recurrence become a correctly owned, artifact-bound executable state?

1. Constructor: parameter shapes, vocabulary and content digest bind tenant/request state.
2. Ingest: valid token rows, masks and exact positions; prompt consumption does not emit text.
3. Native step: embedding, input gate, diagonal retention, addition and output projection, with shapes.
4. Chunks: affine composition and independent scalar closed form; autograd continuity is a separate obligation.
5. Output: one-token shift and an exact rational trace; generation is not training or genomic capability.
6. Shell: reserve, stage, fence and commit, including cancellation and backpressure with native state unchanged.

Six editable algorithm plates with semantic TXT companions. Twenty worked questions. This is a restricted non-Transformer teaching recurrence, not full DOGMA implementation parity.
