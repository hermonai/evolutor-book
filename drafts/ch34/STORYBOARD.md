# Chapter 34 storyboard — before prose

1. Two clocks: lanes A/B/C over three ticks; B finishes and C enters. Label local token positions separately from scheduler ticks; no biological causation implied.
2. Identity-preserving gather: noncontiguous slots carry owner, generation and version; vector rows retain a lane map; scatter returns by identity, not row number.
3. Mask as identity: active state takes the native gated recurrence; inactive state bypasses arithmetic and position advance. Contrast zero-input decay.
4. Completion fence: pin, compute, cancel/retire, acknowledge, reclaim; one lane can be rejected while a sibling commits. Not an atomic batch transaction.
5. Layout and axes: [request,state] strides, request permutation and sequence scan as distinct axes. No universal SoA performance claim.
6. Fusion boundary: explicit compulsory kernel traffic versus extra gather/scatter and an intermediate write/read; generated bytes, not device measurements.

All six plates are editable TikZ plus semantic TXT. Values come from the actual Chapter 31 native recurrence and Chapter 32/33 pool bridge. Figures show computation, not molecular biology. Build-generated source listings, churn trace and byte table follow the tested reference.
