\chapter*{Sources and further reading}
\addcontentsline{toc}{chapter}{Sources and further reading}
Sections 3.1--3.5 of the original Transformer paper were inspected for the baseline sublayers and sinusoidal positions. Xiong and colleagues' abstract and introduction were inspected for the pre-/post-normalization distinction; their mean-field theory and benchmarks are not reproduced. PyTorch 2.10 API descriptions were inspected for normalization statistics, block configuration, GELU, and explicit dropout mode. Access checked 20 September 2026.

The local tests use PyTorch 2.10.0, CPU float64. The seeded training trace is a synthetic training-set calculation, not a validation or biological benchmark.

\section*{Selective glossary}
\addcontentsline{toc}{section}{Selective glossary}
\textbf{Residual stream:} representation preserved and incrementally modified by branch additions.
\textbf{Pre-normalization:} normalization of a branch input before its learned transformation.
\textbf{VJP:} vector-Jacobian product propagating a scalar objective's sensitivity backward.
\textbf{Absolute position:} sequence coordinate independent of chunk boundaries.
\textbf{Legal target edge:} a next-token prediction admitted by validity and record identity.
