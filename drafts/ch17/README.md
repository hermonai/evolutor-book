# Chapter 17: Traces, credit and mechanistic evidence

Standalone authored-LaTeX review candidate. Earlier accepted editions remain unchanged.

Derivations, runnable reference models, original editable TikZ figures, semantic TXT companions and twelve worked exercises. Numerical tables and plots are generated from reference.py. Access depth and evidence limits are recorded in sources.tex.

Run from the repository root with Python 3.13 and the project dependencies:

```sh
python3 drafts/ch17/build.py --assets-only
python3 -m pytest tests/test_ch17_reference.py
python3 drafts/ch17/build.py --render
python3 drafts/ch17/build.py --check
```

Local output: output/pdf/evolutor-ch17-review.pdf. PDFs are generated, not committed.

Independent specialist review, reader feedback and cumulative integration remain open.
