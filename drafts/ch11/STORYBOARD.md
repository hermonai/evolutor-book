# Chapter 11: Regulation and expression across levels

Author-approved storyboard, 24 September 2026. Approval means an author design decision, not independent scientific review.

Scope: original implementation-first chapter; preserve all prior chapters and accepted editions. Each plate is authored as editable TikZ with a semantic TXT companion. Computed labels come from tested reference artifacts. Inspect print-size color and grayscale renderings.

1. **01-promoter**: A DNA duplex with overlapping promoter/operator, mutually exclusive empty/polymerase/repressor states. Draw molecule silhouettes, backbone, paired strands and transcription arrow; statistical weights are assigned model variables.

2. **02-expression**: DNA template to nascent RNA, ribosome on RNA and growing peptide; separate transcription, translation and degradation arrows, label bacterial coarse-grained setting. DNA is retained, not consumed as fuel.

3. **03-response**: Computed step responses for RNA and protein with different degradation rates, exposing memory after the input changes. Concentrations in assigned units, minutes on time axis.

4. **04-identifiability**: Two kinetic parameter sets share steady state but differ in transient trajectories; compute values from exact propagation. A single protein snapshot cannot identify transcription versus translation.

5. **05-contract**: Explicit semantic mapping: stored definition, context, eligibility, amount state, executed output. Diagram state update versus instantaneous routing, with a counterexample equal present input/different past state. Software analogy is not a biological implementation.

Acceptance: derive the governing relationships, test independently solvable limits and counterexamples, include worked exercises and primary-source access notes. Review source/PDF hashes; cumulative integration and independent specialist/reader review remain open.
