## 01-clocks

Question: Which object changed?

One inference state trajectory inside a fixed-parameter interval, weight updates inside a fixed-graph interval, and generation boundaries between candidate graphs. Caption: clocks specify causality, not necessarily wall-clock scale. Risk: software mechanisms are not literal biological evolution.

Question: How can learning prefer a spurious feature?

Two feature axes, independent evaluation shift, and masked weight entries. Training correlation differs from validation correlation; target mechanism remains fixed. Caption: good training fit need not transfer. Risk: synthetic case not genomic evidence.
