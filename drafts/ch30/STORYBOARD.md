# Chapter 30 figure storyboard

1. Envelope: tenant, request, pinned model, clock and bounds bind admission.
   Identifying fields do not confer execution authority.
2. Lifecycle: phase, terminal winner and resource status are separate axes.
   Completed does not mean cleaned.
3. Ownership: increasing lease generations and committed revisions prevent
   stale same-ID updates, including ABA reuse.
4. Queue: worst-case reservation separates item, byte and generation bounds.
5. Cancellation: logical terminal selection precedes physical acknowledgement.
   Output is fenced and buffer release waits.
6. Trace: ordered events reconcile work and output with different equations;
   local dequeue is not remote delivery.
