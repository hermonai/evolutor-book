\chapter*{How to use this preview}
This is the first chapter of a new undergraduate edition, not a completed textbook. Later chapter references point to the approved teaching plan. Earlier editions remain separately preserved.

Read pictures with their captions, try worked examples by hand, and attempt exercises before opening the answers. The Python section is optional. Linked glossary entries return to the section teaching each term; the index points to substantive definitions.

Figures are original editable vector artwork with Unicode TXT companions. Their captions state the simplifications. This preview contains no new laboratory result or claim of a research-model advantage.

Review so far is internal author-agent review using beginner and specialist perspectives. It is not independent expert certification, a learner study or an accessibility-conformance certification. The repository includes sources, tests, build instructions and a candid production report.
