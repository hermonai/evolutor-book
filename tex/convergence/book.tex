\chapter*{Reading and evidence conventions}
\addcontentsline{toc}{chapter}{Reading and evidence conventions}
This continuous manuscript assembles authored LaTeX, not previously exported PDFs.
Begin with the worked problem, derive the mechanism, run the reference, inspect
its state or values, and try the counterexample. The implementation-first
teaching progression is general pedagogy; the book's prose, code and illustrations
are its own. External model names and biological analogies are not proof of novelty.

A mathematical result holds under stated premises. A passing test checks the
implemented function on declared cases. A simulated trace is not a laboratory
measurement, and a synthetic model result is not a genomic capability benchmark.
Source notes record access depth; local technical and visual review are distinct
from independent specialist and reader review. Historical accepted editions
remain unchanged. This candidate has not inherited their acceptance.

Chapter boundaries preserve each mechanism's units, information access, state
ownership and failure contract. The single bibliography reconciles exact source
identifiers while retaining the source-key provenance in the build record.
The global index is generated from authored term marks. All 52 chapters have
authored sources in this candidate. Integration does not turn separately tested
components into a production service: chapter-specific interface and evidence
limits still apply. The companion repository records package adoption, local
reviews and unresolved pre-publication work separately from this reading text.
