\PartQuestion{Can a non-Transformer, DNA-native state organization be specified precisely enough to be falsified?}
DOGMA is assembled in five steps: a DNA-addressed state primitive, selective regulation, structured memory with explicit clocks, strand and complement actions, and finally a frozen reference model with a falsification matrix. Each step adds a capability only together with a counterexample it resolves and a test that could reveal its failure. The part ends with honest pilot results. The DOGMA reference sits near chance on a deliberately small motif task, and the chapter explains which experiments would decide whether its mechanisms are worth keeping.
