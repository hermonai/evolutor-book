\chapter*{Chapter 2 glossary}\addcontentsline{toc}{chapter}{Chapter 2 glossary}
\begin{description}
\item[Information contract] The inputs and state that a prediction is permitted to depend on, including preprocessing, retrieval and target alignment.
\item[Conflict component] A connected component of record relationships that prohibit cross-fold separation. Guarantees cover only the supplied or detected relations.
\item[Finite intervention] A behavior test that changes a selected input region and compares outputs required to remain invariant. Passing finitely many cases is not a universal proof.
\item[Entropy control] An analytical reference under a specified data distribution and information boundary; iid uniform DNA has next-base entropy $\ln4$ nats.
\item[Scoring denominator] The number of valid events or represented raw bases used to normalize total negative log likelihood. Mask and tokenizer conventions matter.
\item[Removal and transplant] Interventions that remove a component from one system or add it to another. They test different causal explanations under declared budgets.
\item[Engine fidelity] Agreement of an implementation with a trusted numerical reference for the same model, weights and inputs; distinct from task capability.
\end{description}
