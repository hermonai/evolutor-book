# Terminology contract

| Term | Meaning and boundary |
| --- | --- |
| DNA computing | Information processing physically implemented with DNA-containing molecular systems; specify chemistry and readout. |
| DNA sequence model | A digital model whose input/output concerns DNA sequences; not necessarily DNA computing. |
| Nucleoside / nucleotide | Base plus sugar / nucleoside with phosphate group(s); distinguish free substrates and polymer residues. |
| Complement / reverse complement | Base mapping / base mapping plus reversal; direction labels are mandatory on duplex diagrams. |
| Regulation (biology) | Context-dependent biological control, with a named physical mechanism. |
| Regulation (software) | A defined selection or control rule; compare to routing or conditional execution. |
| Gene / genome (software) | Candidate module / stored representation; neither implies biological equivalence. |
| Development | A process constructing a phenotype; a software analogue needs construction semantics. |
| Evolution | Population-level variation and selection in biology; software edits alone do not establish it. |
| Generalization / transfer | Performance on a specified held-out distribution / adaptation across specified tasks or domains. |
| AGI | A contested capability classification requiring an explicit operational framework and broad evidence. |

No architecture family is inferred from a name. No new biological terminology replaces a known CS term without a useful distinction.
