E10 — LONG-CONTEXT CAPABILITY MAP: RETRIEVAL VS ACCUMULATED STATE
Scope: separates tasks that require addressable past content from tasks compressible into running state.

LEGEND

EVALUATION AXES
  context extrapolation · distractors · query distance · state/KV bytes · compute · error accumulation.

BOUNDARY RULE
  success on running aggregates ⊣ exact retrieval superiority;
  success on retrieval          ⊣ efficient streaming-state superiority.

READING NOTES
1. “Long context” is not one capability; benchmarks must isolate the information requirement.
2. Fixed state may solve a running statistic perfectly and fail exact recall for principled capacity reasons.
3. Attention may retrieve well while paying growing memory or compute costs; those costs stay in the result.
