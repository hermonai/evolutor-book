E12 — COMMON SERVING PROTOCOL OVER DISTINCT INFERENCE ENGINES
Scope: proposes a shared request lifecycle without pretending that KV, recurrent, and GCS state are equivalent.

ABSTRACTION-LEAK RULES
  fixed `kv_bytes` field ⊣ recurrent/GCS equivalence; generic `state_bytes` is allowed.
  `step(token)`          ⊣ all symbolic event semantics; typed events may be required.

READING NOTES
1. The common layer owns lifecycle and observability; each engine owns state semantics.
2. Conformance means declared behavior and errors match the protocol, not equal internal algorithms.
3. The protocol should be built only after real engines expose stable shared requirements.
