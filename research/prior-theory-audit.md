# Prior-theory and naming audit

## GCS

The five-part tuple is a historical candidate organizing alphabet, stored representation, regulation, expression and evolution. It does not itself distinguish a new computational class. Conditional execution, arbitrary external primitives and unbounded memory can make an apparent universality argument trivial or move all power into an assumed primitive.

Decision: retain as a case study only. Derive a minimal operational semantics after selecting a useful workload. Type soundness, cost and learning claims remain separate obligations. See [the theorem audit](theorem-ledger.md).

## Expression complexity

Counting fired nodes omits selection, scheduling, data movement, primitive work and output. If no node fires but all gates must be evaluated, a zero firing count cannot bound total runtime. Keep explicit resource accounting, not the inherited scalar as a universal complexity result.

## Double strands and biological constants

Canonical reverse complement is an exact symbolic symmetry. A redundant copy does not automatically add information or neural ability. Proposal/verifier and state/checksum pairs may be useful existing engineering patterns; they are not consequences of DNA chemistry. No biological initialization constant is a validated physical mechanism in a digital network.

## DOGMA and Hermon DNA

Read-only source audit distinguishes:
- DOGMA engine documents: uncommitted recurrent-state implementation notes, content hash `d860a8d535f8a9aaa371d736892192dfcf118a2671e317dc1117ea6c71545339` for ARCHITECTURE.md. Not a trained-model result.
- evo-trainer at `610117f0c6f73eed12d7bfba1478696512fb52c2`: configuration-dependent historical model; initial code exposes optional attention and scan paths. Do not label every version recurrent-only or claim this commit includes later untracked causality repairs.
- Hermon Engine at `472a44cdb511b2dae6c9569e59543db8f8350b25`: serving/backend work including a paged-attention path; not evidence that a proposed Hermon DNA architecture exists or wins.
- dna2agi at `49e6fa790a6faaa2b470881f058fdf8fcd69e1ab`: research/library history, including a withdrawn mechanism claim; not a model family.

These related repositories were inspected, not modified. Dirty files are not identified by HEAD alone. The snapshot's architecture-dogma-r.json overgeneralizes one trainer configuration; it is preserved as historical evidence and not used as a valid new result manifest.

Decision: **DOGMA and Hermon DNA remain unassigned candidate research names**. No rename, merger, pretrained-model endorsement or engine rewrite is part of this reset. The old Transformer/non-Transformer branding split is a hypothesis to revisit after comparisons.
