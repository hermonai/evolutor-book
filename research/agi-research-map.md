# AGI research and capability map

AGI classification is a conclusion requiring an operational definition, not a synonym for progress. E-S10 offers one framework, not a certification standard. E-S11 supplies an existing world-model research comparison. This reset adopts no claims about the assistant's benchmark performance or AGI status.

| Capability | Operational question | Required counter-test |
| --- | --- | --- |
| Generalization | Does performance persist on a specified unseen distribution? | Distribution shift, contamination and memorization |
| Transfer | Does prior learning reduce cost on new tasks? | Equal-budget training from scratch |
| Reasoning | Does behavior follow dependencies across novel instances? | Shortcut and counterfactual variants |
| Planning | Does action selection improve delayed outcomes? | Reactive policy and model-error controls |
| Continual learning | Can new tasks be learned while retaining old ones? | Forgetting curve and growing-resource baseline |
| Memory | What can be stored, recalled or accumulated? | Interference, exact retrieval and precision bounds |
| Adaptation | How quickly can behavior adjust? | Extra-data and memory-only baselines |
| Tool use | Can external operations be selected and checked? | Equal tool access and permission boundaries |
| World modeling | Are transition predictions useful for decisions? | Held-out interventions and open-loop baselines |
| Self-improvement | Does an accepted change improve specified behavior? | Frozen system, human effort and search-budget controls |
| Metacognition | Does confidence/error detection predict failures? | Calibration and selective-accuracy tests |
| Open-ended learning | Does a stream yield reusable new competence? | Fixed curriculum, resource growth and novelty definition |
| Autonomy | Which actions occur without further direction? | Permission, reliability and recovery tests |
| General intelligence / AGI | How broad and reliable is the capability portfolio? | Independent multi-domain evaluation and limits |

Claim types: DEFINITION, OBSERVATION, BENCHMARK RESULT, MECHANISTIC INTERPRETATION, HYPOTHESIS, ENGINEERING ASPIRATION, AGI CLAIM. State type separately from evidence status. All comparative scorecard cells are **not measured** in this reset. A DNA task cannot populate a natural-language, planning or AGI cell.
