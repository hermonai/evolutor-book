# Continuity
EVOD-30 defines request lifecycle and logical ownership. EVOD-31 defines request/model-bound DOGMA state construction and causal/chunk-equivalent execution. EVOD-32 maps that logical state to reusable physical memory without changing semantics. Pool slots are storage, not identity. Every allocation returns a generational handle binding pool, slot, generation, request and model. Release scrubs state and increments generation; stale handles are invalid even if the same slot is immediately reused. Clone creates independent mutable state; aliasing is forbidden here. Temporary workspace has step scope and cannot be retained as persistent state. Chapter 33 may introduce explicit checkpoints/prefix sharing only on top of these ownership rules.
