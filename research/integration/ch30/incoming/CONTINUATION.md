# Continuity contract
EVOD-29 froze benchmark/evidence contracts; EVOD-30 begins the DOGMA Engine. Model semantics remain owned by EVOD-18–22 and execution parity by EVOD-26. This chapter defines the serving boundary without inventing new learned capability. Every request has immutable identity/model binding, explicit owner, deadline and lifecycle. State is allocated only after admission; streaming is bounded by backpressure; cancellation/deadline/error transitions are terminal; cleanup is idempotent; no state crosses tenants/requests without an explicit clone/share contract. A runtime trace is operational evidence, not a capability claim.
