\chapter*{Author technical review}
\begin{itemize}
\item Authorization is deny-by-default and external to model text.
\item Capabilities bind tenant, subject, action and resource.
\item Tenant identity participates in cache/object namespaces.
\item Per-tenant quotas are tested.
\item Prompt/retrieval content cannot mint authority.
\item Audit records omit stored secret values.
\item Cryptographic authentication, sandbox hardening and distributed enforcement require production implementations beyond this oracle.
\end{itemize}
