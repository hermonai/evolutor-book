\chapter*{Source notes}
\begin{itemize}
\item NIST SP 800-207, \emph{Zero Trust Architecture}: no implicit trust based solely on network location; authentication/authorization are explicit resource-access decisions.
\item OWASP GenAI LLM01 Prompt Injection guidance: least privilege, external privilege control, segregation of untrusted content and approval for high-risk actions.
\item OWASP LLM07 System Prompt Leakage guidance: critical authorization and privilege separation must be enforced independently from the LLM.
\item EVOD-32--33, 39--40 and 44 provide state ownership, runtime policy, memory and service boundaries.
