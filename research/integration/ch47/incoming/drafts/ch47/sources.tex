\chapter*{Source notes}
\begin{itemize}
\item Williams, Waterman and Patterson (2009), \emph{Roofline: An Insightful Visual Performance Model for Multicore Architectures}: arithmetic intensity and compute/memory ceilings as a performance bound framework.
\item NVIDIA Nsight Systems documentation: system-wide CPU/GPU timelines, CUDA/API/memory tracing and NVTX-focused regions.
\item NVIDIA Nsight Compute documentation: detailed per-kernel CUDA performance metrics and analysis.
\item PyTorch \texttt{torch.profiler} documentation: operator costs, shapes/stacks, device kernel activity and execution traces for training/inference.
\item EVOD-44 defines service SLO observability; EVOD-46 defines placement/transfer costs to be calibrated here.
\end{itemize}
