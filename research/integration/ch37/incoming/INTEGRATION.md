# Integration contract

Integrate only after replaying EVOD-35 full/cached parity through the selected precision path and validating EVOD-36 page ownership under batch churn. Benchmark TTFT, ITL/TBT, request latency, throughput and p50/p95/p99 separately under declared arrival/prompt/output distributions.

Any FP8/INT8/KV quantization configuration requires hardware-kernel support, calibration/evaluation provenance, baseline quality results and explicit fallback. Build/render/independent review remain separate gates.
