# Continuity
EVOD-18–22 define DOGMA's proposed state semantics; EVOD-26 requires sequential/chunk execution parity; EVOD-28 binds model artifacts; EVOD-30 defines request lifecycle, admission, ownership, cancellation, deadlines, streaming and cleanup. EVOD-31 executes only inside an admitted RUNNING request. It constructs state from an explicit model artifact, ingests prompt tokens causally, advances one native step at a time, preserves chunk continuation exactly, applies an output head, and emits trace records without exposing hidden chain-of-thought. Full-record suffix-derived dual features remain forbidden for ordinary left-to-right decoding.
