# Continuity
Canonical EVOD-25 is `Shared experiments without false equivalence`. EVOD-22 fixed
DOGMA's non-Transformer state/memory contract; EVOD-23 fixed Hermon DNA's Transformer
contract and retained a failed motif experiment; EVOD-24 froze genomic data/objective
semantics and proved the motif labels with an independent oracle. EVOD-25 defines a
comparison harness that shares data and metrics while preserving model-native state,
legal information access and resource semantics. It explicitly forbids forcing
DOGMA and Hermon into an identical execution API when that would erase the hypothesis.
