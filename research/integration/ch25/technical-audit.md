# EVOD-25 convergence audit

Decision: substantially rewrite the r01 comparison outline into executable split,
uncertainty and native-execution mechanisms. Preserve prior 24's DNA geometry.
Do not repeat the incoming old single-run 47.7-percent pilot as current evidence.

EVOD25-T1: prohibited-cross-partition relationships define a graph whose connected
components must each occupy one partition. Exact/RC identity, declared groups and
curated links require joint transitive closure; row-local checking is insufficient.
EVOD25-T2: paired correctness differences capture covariance. Sample variance
divided by N estimates variance of the mean under iid evaluation-record premises.
EVOD25-T3: uniform cluster resampling with all rows retained estimates a
record-weighted difference as a ratio of totals, not an equal-weight cluster mean.
The finite percentile interval is approximate and conditional on fixed predictors.
EVOD25-T4: model-native execution parity is a prerequisite for comparing schedules,
not trained genomic capability. Full DOGMA carry includes both h and m; stateless
Hermon repeated-prefix execution is not a KV cache.

EVOD25-E1 (tested): 26 tests include independent BFS closure, split falsifiers,
row-order invariance, hash binding, threshold boundaries, missing-class metrics,
paired variance, exact enumerated cluster support, unequal cluster sizes and
actual native parity plus independent parameter arithmetic.
EVOD25-E2 (assigned synthetic trace): GC threshold is selected only on 240
training rows; 80 test rows give 39 correct versus 80 for a known motif oracle.
The observed difference 0.5125 and seeded interval [0.4,0.625] do not compare
trained architectures or establish genome-wide generalization.
EVOD25-E3 (tested native probe): actual references yield DOGMA 602 and Hermon 958
parameters; complete DOGMA batch-one float64 state is 256 bytes. Hermon has
72 semantic legal edges per layer. These are inventories, not matched budgets.

EVOD25-F1: transitive train/test dependence survives a direct-edge-only audit.
EVOD25-F2: four eight-row perfectly correlated clusters produce a much wider
interval than treating their 32 rows as independent.
EVOD25-F3: all-negative GC threshold must exceed one; choosing one misclassifies
a pure-GC sequence. A missing class makes balanced accuracy unavailable.
EVOD25-O1: no new genomic training, optimized kernel, KV implementation, latency,
energy or independently replicated benchmark is claimed. Curation adequacy,
sampling model, external validation and scientific review remain open.

The Chapter 21 full-record RC representation remains offline and is not introduced
into causal prediction. Model names retain DOGMA/Hermon/Evolutor taxonomy.
