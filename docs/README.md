such as UNDERGRADUATE_REBUILD_REPORT.md, DEEP_CHAPTER_1_REPORT.md and earlier
reset/review reports describe their dated editions. They remain provenance,
not active chapter counters or instructions to restart those editions. Earlier
continuous-throughNN-review.json records bind earlier source states; consult
continuous-through52-review.json for the new complete-range candidate.

Do not delete historical sources or rewrite old acceptance claims to make the
repository appear tidy. Derived build/ and tmp/ files are regenerable local
artifacts; source, provenance, tests and reviewed release artifacts are not cache.
