# Evidence legend

Evolutor crosses several disciplines, so every important statement is labeled by kind:

- established biology;
- established computer science;
- established DNA-computing result;
- source-derived Evolutor claim;
- implemented mechanism;
- measured result;
- engineering analogy;
- hypothesis;
- conjecture;
- open question.

Formal definitions do not prove performance. Executable code does not prove a theorem. A benchmark does not establish biological faithfulness. A biological analogy does not determine software semantics.
